# Specialist Guilds Reference

## 1. Systems Guild
Focus: High-performance computing, memory safety, concurrency, low-level tooling.
Languages: Rust, C++, Zig, Go.

## 2. Web Guild
Focus: Full-stack architectures, modern reactive UI, type-safe API contracts.
Languages & Tools: TypeScript, React, Next.js, Node.js, Tailwind CSS.

## 3. Cloud & DevOps Guild
Focus: Infrastructure as Code, container orchestration, resilient delivery pipelines.
Tools: Docker, Kubernetes, Terraform, GitHub Actions, AWS, GCP.

## 4. Data Guild
Focus: High-throughput ingestion, data modeling, analytical queries, vector stores.
Technologies: SQL, PostgreSQL, ClickHouse, Kafka, USearch.

## 5. Mobile Guild
Focus: Native and cross-platform mobile experiences.
Technologies: Flutter, Dart, Swift, Kotlin.

## 6. Security Guild
Focus: Threat modeling, cryptography, vulnerability mitigation, secure secrets.

## 7. Intelligence Guild
Focus: Machine learning pipelines, RAG systems, embedding spaces, model evaluation, generative 3D/multimodal integrations.

## 8. Experience Guild
Focus: Design systems, ergonomics, WCAG accessibility, user flows, interactive 3D viewports.

## 9. Strategy & Ops Guild
Focus: System architecture, SRE observability, operational milestones.

## 10. Quality Guild
Focus: Test-driven development (TDD), property testing, automated verification, asset linting.

## 11. Spatial & 3D Engineering Guild
Focus: AAA+ 3D modeling, high/low-poly workflows, quad-dominant retopology, MikkTSpace PBR baking, skeletal rigging & FACS blendshapes, procedural geometry synthesis, shader programming, and game engine integration.
Tools & Standards: Blender Python (`bpy`), Godot 4.x (`.tscn`/`.tres`/GDExtension), glTF 2.0 (KHR extensions), OpenUSD, V-HACD, PBR Metallic/Roughness, Nanite/LOD architectures.
