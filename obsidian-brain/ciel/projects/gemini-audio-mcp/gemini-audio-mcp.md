## Use and scope

This project implements a Model Context Protocol server in Rust that generates adaptive, context-aware environmental soundscapes and professional audio via Google's Gemini 2.0 Multimodal Live API. It targets AI agents, creative tooling, and MCP-compatible workflows that need on-demand audio generation.
