# v1.11.6–v1.11.7 Stabilization Release

Release summary for the v1.11.6 and v1.11.7 patch releases, focusing on CI hardening, web compatibility, and publishing regression fixes.

## v1.11.7 (2026-07-11)

### Fixed
- **Publishing regression**: Removed direct `xml` and `dart_udx` dependencies that were accidentally declared in v1.11.6. They conflicted with downstream consumers such as `port_forwarder` (which constrains `xml ^6.5.0`). Security pins remain as `dependency_overrides` for local development and CI.

### Verification
- `dart analyze`: 0 issues
- `dart test`: 3478 passed, 8 skipped, 0 failed
- CI: all workflows green
- pub.dev: `dart_ipfs 1.11.7` live
- Docker: `ghcr.io/jxoesneon/dart-ipfs:1.11.7` published

## v1.11.6 (2026-07-11)

### Fixed
- **CI/Test**: Made `IPFSWebNode` start offline by default and updated web/core tests to use `offline: true`, eliminating platform-specific router startup failures in CI.
- **Gateway**: Fixed HTTPS redirect `Location` header to include the leading slash in the request path (`/${request.url}`).
- **Formatting**: Re-formatted `test/interop` test files to match the Linux CI `dart format` style.
- **Web compatibility**: Preserved Flutter web compilation by keeping conditional imports for `Int64` literal and native QUIC paths.

### Changed
- **CI/CD**: Test workflow is now green on Ubuntu, macOS, and Windows (3477 passed, 8 skipped).

## Key lessons

1. **Dependency override discipline**: Security pins (`xml`, `dart_udx`) must stay as `dependency_overrides`, never promoted to direct deps. Downstream consumers like `port_forwarder` have tighter version constraints.
2. **Offline-by-default for tests**: `IPFSWebNode` must start offline in CI to avoid platform-specific network startup failures.
3. **Cross-platform formatting**: `dart format` output can differ between Windows and Linux — interop test files must be formatted on Linux for CI consistency.
4. **Conditional imports for web**: `Int64` literals and native QUIC paths need conditional imports to preserve Flutter web compilation.
