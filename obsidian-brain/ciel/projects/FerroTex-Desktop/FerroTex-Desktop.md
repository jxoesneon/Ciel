## Use and scope

A hybrid Rust + TypeScript monorepo building a Tauri v2 desktop app that hosts the FerroTeX LaTeX engine and a React 19 frontend. Supports real-time collaboration (Yjs), AI assistance (Ollama), Jujutsu VCS integration, and Zotero sync.
